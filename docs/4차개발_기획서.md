## 2. Phase 1 — 게시판/공지사항

### 2.1 개요

| 항목 | 내용 |
|------|------|
| 기능명 | 게시판 / 공지사항 |
| 대상 | 팀 멤버 전원 |
| 목적 | 팀 내 공지사항, 업무 안내, 자료 공유 |
| 위치 | 사이드바 메뉴 추가 |

### 2.2 게시판 유형

| 유형 | 설명 | 권한 |
|------|------|------|
| **공지사항** | 팀 전체 공지 (상단 고정 가능) | 작성: owner/admin, 열람: 전체 |
| **자유게시판** | 자유로운 소통 | 작성: 전체, 열람: 전체 |
| **자료실** | 파일/문서 공유 | 작성: 전체, 열람: 전체 |

### 2.3 기능 상세

| 기능 | 설명 |
|------|------|
| 글 작성 | 제목 + 본문(리치 텍스트, Quill.js 활용) + 파일 첨부 |
| 글 목록 | 페이지네이션 + 검색(제목/내용) + 카테고리 필터 |
| 글 상세 | 본문 열람 + 첨부파일 다운로드 + 조회수 |
| 댓글 | 게시글에 댓글 작성/삭제 |
| 공지 고정 | owner/admin이 게시글을 목록 상단에 고정 |
| 수정/삭제 | 본인 글 수정/삭제 + owner/admin은 모든 글 삭제 가능 |

### 2.4 DB 모델

```
Board (게시판)
├── id, team_id, name, type (notice/free/archive), created_at

BoardPost (게시글)
├── id, board_id, author_id, title, content, is_pinned
├── view_count, file_urls (JSON), created_at, updated_at

BoardComment (댓글)
├── id, post_id, author_id, content, created_at
```

### 2.5 API 설계

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/teams/{team_id}/boards` | 게시판 목록 |
| POST | `/teams/{team_id}/boards` | 게시판 생성 |
| GET | `/boards/{board_id}/posts` | 게시글 목록 |
| POST | `/boards/{board_id}/posts` | 게시글 작성 |
| GET | `/posts/{post_id}` | 게시글 상세 |
| PUT | `/posts/{post_id}` | 게시글 수정 |
| DELETE | `/posts/{post_id}` | 게시글 삭제 |
| PATCH | `/posts/{post_id}/pin` | 공지 고정/해제 |
| POST | `/posts/{post_id}/comments` | 댓글 작성 |
| DELETE | `/comments/{comment_id}` | 댓글 삭제 |

### 2.6 화면 구성

| 화면 | 설명 |
|------|------|
| 게시판 목록 | 사이드바 "게시판" 클릭 → 카테고리 탭 (공지/자유/자료) |

## 3. Phase 1 — 미가입 사용자 이메일 초대

### 3.1 개요

| 항목 | 내용 |
|------|------|
| 기능명 | 이메일 초대 (미가입 사용자) |
| 대상 | owner/admin |
| 목적 | 아직 가입하지 않은 사용자를 팀에 초대 |
| 현재 문제 | 상대방이 먼저 Google 로그인해야만 초대 가능 |

### 3.2 초대 플로우

```
1. owner/admin이 이메일 입력 → "초대" 클릭
2. DB에 PendingInvite 레코드 생성 (token, team_id, email, role, expires_at)
3. Resend API로 초대 이메일 발송 (초대 링크 포함)
4. 수신자가 초대 링크 클릭 → 초대 수락 페이지
5. Google 로그인 진행 → 계정 생성 + 자동으로 해당 팀 합류
6. PendingInvite 상태를 accepted로 변경
```

### 3.3 DB 모델

```
PendingInvite (대기 초대)
├── id, team_id, email, role (기본: member)
├── token (UUID), invited_by (user_id)
├── status (pending/accepted/expired)
├── created_at, expires_at (7일)
```

### 3.4 API 설계

| 메서드 | 경로 | 설명 |
|--------|------|------|
| POST | `/teams/{team_id}/invites` | 초대 발송 |
| GET | `/teams/{team_id}/invites` | 대기 초대 목록 |
| DELETE | `/invites/{invite_id}` | 초대 취소 |
| GET | `/invites/accept/{token}` | 초대 수락 페이지 |
| POST | `/invites/accept/{token}` | 초대 수락 처리 |

### 3.5 이메일 템플릿

```
제목: [Contract Sync] {팀명} 팀에 초대되었습니다

본문:
안녕하세요,
{초대자명}님이 Contract Sync의 "{팀명}" 팀에 초대했습니다.

아래 버튼을 클릭하여 팀에 합류하세요.

[팀 합류하기] → https://{domain}/api/v1/invites/accept/{token}

이 초대는 7일 후 만료됩니다.
```

## 6. Phase 3 — 멤버 간 채팅

### 6.1 개요

| 항목 | 내용 |
|------|------|
| 기능명 | 멤버 간 실시간 채팅 |
| 대상 | 같은 팀 멤버 |
| 목적 | 외부 메신저 없이 서비스 내 커뮤니케이션 |
| 통신 방식 | SSE (Server-Sent Events) — 기존 알림 인프라 활용 |

### 6.2 채팅 유형

| 유형 | 설명 |
|------|------|
| **1:1 채팅** | 두 멤버 간 개인 대화 |
| **그룹 채팅** | 3명 이상 그룹 대화 (채팅방 생성) |
| **프로젝트 채팅** | 프로젝트별 자동 생성 채팅방 (선택) |

### 6.3 기능 상세

| 기능 | 설명 |
|------|------|
| 채팅방 목록 | 사이드바 "채팅" 메뉴 → 최근 대화 목록 |
| 메시지 전송 | 텍스트 + 파일 첨부 (이미지/문서) |
| 실시간 수신 | SSE로 새 메시지 실시간 수신 |
| 읽음 확인 | 메시지 읽음/안읽음 표시 |
| 안읽은 수 | 채팅방별 안읽은 메시지 수 뱃지 |
| 검색 | 채팅 내용 검색 |
| 알림 연동 | 새 메시지 시 알림 발송 |

### 6.4 DB 모델

```
ChatRoom (채팅방)
├── id, team_id, name (그룹채팅용), type (direct/group/project)
├── project_id (프로젝트 채팅 시), created_at

ChatRoomMember (채팅방 참여자)
├── id, room_id, user_id, joined_at, last_read_at

ChatMessage (메시지) — 기존 ChatMessage와 별도
├── id, room_id, sender_id, content, file_urls (JSON)
├── created_at
```

### 6.5 API 설계

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/chat/rooms` | 내 채팅방 목록 |
| POST | `/chat/rooms` | 채팅방 생성 (1:1 또는 그룹) |
| GET | `/chat/rooms/{room_id}/messages` | 메시지 목록 (페이지네이션) |
| POST | `/chat/rooms/{room_id}/messages` | 메시지 전송 |
| PATCH | `/chat/rooms/{room_id}/read` | 읽음 처리 |
| GET | `/chat/stream` | SSE 실시간 메시지 스트림 |

### 6.6 화면 구성

| 화면 | 설명 |
|------|------|
| 채팅 목록 | 채팅방 리스트 + 안읽은 수 뱃지 + 마지막 메시지 미리보기 |
| 대화 화면 | 메시지 버블 + 입력창 + 파일 첨부 버튼 |
| 채팅방 생성 | 멤버 선택 → 그룹명 입력(선택) → 생성 |

├── id, team_id, default_check_in, default_check_out
