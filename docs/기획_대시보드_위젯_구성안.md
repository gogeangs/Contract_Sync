> 작성일: 2026-03-18 | 우선순위: B | 대상: 프론트엔드 개발자

## 1. 현황

현재 대시보드는 **12개 위젯**이 모든 사용자에게 동일하게 표시됨.
PM, 디자이너, 개발자 등 역할에 따라 필요한 정보가 다르므로 **역할별 기본 위젯 구성**을 제안.

## 4. 커스터마이징 UX

### 4-1. 위젯 토글 UI
- 대시보드 우측 상단에 **⚙️ 위젯 설정** 버튼 추가
- 클릭 시 드롭다운/모달로 위젯 목록 + ON/OFF 토글 표시
- W1, W2는 "고정" 뱃지 표시, 토글 비활성화

### 4-2. 저장 방식
- `localStorage` 키: `cs_dashboard_widgets_{userId}`
- 값: `{ "W10": false, "W11": true, ... }` (변경된 것만 저장)
- 저장된 값이 없으면 역할별 기본값 적용

### 4-3. 초기화
- "기본값으로 복원" 버튼 제공
- 클릭 시 localStorage 삭제 → 역할별 기본값으로 리셋

## 5. 구현 참고

| 항목 | 상세 |
|------|------|
| 역할 판별 | `user.role` 또는 팀 내 역할(owner/admin/member) 기준 |
| 레이아웃 | 숨김 위젯은 `x-show`로 처리, DOM은 유지 (토글 시 즉시 표시) |

| 다크모드 | 설정 드롭다운도 dark: 클래스 적용 |
