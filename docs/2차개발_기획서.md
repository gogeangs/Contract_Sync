## 1. 사업자등록증 자동 인식

### 목적
고객 등록 시 사업자등록증/증명원 파일을 업로드하면 AI가 자동으로 정보를 추출하여 입력 폼을 채워줌

### 지원 파일
- PDF, JPG, PNG, WebP
- 최대 10MB

### 추출 항목

| # | 추출 항목 | 매핑 필드 | 필수 |
|---|----------|----------|------|
| 1 | 사업자등록번호 | business_number | ✅ |
| 2 | 상호(법인명) | name | ✅ |
| 3 | 대표자명 | representative | ✅ |
| 4 | 업태 | business_type | |
| 5 | 종목 | business_category | |
| 6 | 사업장 소재지 | address | |
| 7 | 전화번호 | phone | |
| 8 | 법인등록번호 | corp_number | |

### UX 흐름

1. 고객 등록 화면 상단에 "📎 사업자등록증으로 자동 입력" 영역
2. 파일 선택 또는 드래그앤드롭
3. AI 분석 후 폼 자동 채움 + "인식 완료" 표시
4. 사용자가 확인/수정 후 저장
5. 인식 실패 시: "파일을 인식할 수 없습니다. 직접 입력해주세요."

### AI 처리 방식
- Gemini Vision API로 이미지/PDF 분석
- 프롬프트: "사업자등록증에서 사업자번호, 상호, 대표자명, 업태, 종목, 주소, 전화번호를 JSON으로 추출"

### API
- `POST /api/v1/clients/ocr` — 파일 업로드 → OCR 결과 반환

## 2. 프로젝트 생성 시 고객 선택 유연화

### 목적
외주 유형 프로젝트도 고객 없이 생성 가능 + 프로젝트 생성 화면에서 고객 즉시 등록

### 변경사항

| 항목 | 현재 | 변경 |
|------|------|------|
| 외주 유형 고객 | 필수 | 선택 |
| 고객 즉시 등록 | 불가 | 가능 |
| 나중에 고객 연결 | 불가 | 가능 |

### UX 흐름

1. 고객 검색에서 결과 없을 때 "검색 결과가 없습니다. [+ 새 고객 등록하기]" 표시
2. 클릭 시 모달로 고객 등록 → 등록 후 자동 선택
3. 고객 없이 생성한 경우: 프로젝트 상세에서 "고객: 미지정 [연결하기]" 표시

### API 변경
- `POST /api/v1/projects` — `client_id` 필드를 Optional로 변경
- `PATCH /api/v1/projects/{id}` — `client_id` 나중에 연결 가능

## 3. 게시판 다중 생성

### 목적
팀에서 게시판을 자유롭게 생성/관리할 수 있도록 확장

### 변경사항

| 항목 | 현재 | 변경 |
|------|------|------|
| 기본 게시판 | 3개 고정 | 3개 기본 + 추가 무제한 |
| 게시판 생성 | 불가 | 관리자/오너만 가능 |
| 게시판 삭제 | 불가 | 관리자/오너만 가능 (기본 게시판 삭제 불가) |
| 게시판 설정 | 없음 | 이름, 설명, 권한 설정 |

### 게시판 생성 설정 항목

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 이름 | 게시판 이름 | 필수 |
| 설명 | 게시판 용도 설명 | 선택 |
| 글쓰기 권한 | 전체 멤버 / 관리자만 | 전체 멤버 |
| 댓글 허용 | 허용 / 비허용 | 허용 |
| 공개 범위 | 팀 전체 / 특정 역할만 | 팀 전체 |

### API
- `POST /api/v1/teams/{team_id}/boards` — 게시판 생성 (관리자/오너)
- `PATCH /api/v1/boards/{board_id}` — 게시판 설정 변경
- `DELETE /api/v1/boards/{board_id}` — 게시판 삭제 (기본 게시판 제외)

## 4. 출퇴근 모드 선택

### 목적
팀별로 자유 출퇴근 / 고정 출퇴근 모드를 선택하여 다양한 근무 환경 대응

### 모드 정의

| 모드 | 출근 | 퇴근 | 지각/조퇴 | 적합한 팀 |
|------|------|------|----------|----------|
| 자유 출퇴근 | 로그인 시 팝업 → 버튼 클릭 | 퇴근 버튼 클릭 | 없음 | 유연 근무, 프리랜서 |
| 고정 출퇴근 | 정책 시간 기준 자동 판단 | 정책 시간 기준 자동 판단 | 지각/조퇴 표시 | 정규 근무, 관공서 |

### 자유 출퇴근 — 출근 흐름

1. 로그인 시 출근 기록 없으면 팝업: "오늘 출근하시겠어요? [출근하기] [나중에]"
2. [출근하기] → 출근 기록 → "출근 기록되었습니다 (09:23)"
3. [나중에] → 팝업 닫힘, 브리핑에서 다시 안내

### 자유 출퇴근 — 퇴근 흐름

1. 대시보드/사이드바에 [퇴근하기] 버튼 상시 노출 (출근 상태일 때만)
2. 클릭 시 AI 업무 자동 요약 → 확인/수정 → [제출 및 퇴근]
3. 업무 보고 저장 + 퇴근 기록

### 근태 기록 표시

| 항목 | 자유 모드 | 고정 모드 |
|------|----------|----------|
| 상태 | 정상 (항상) | 정상/지각/조퇴/결근 |

### API 변경
- `AttendancePolicy` 모델에 `mode` 필드 추가: "free" / "fixed"
- 출근/퇴근 API에서 mode에 따라 지각/조퇴 판단 분기

## 5. 플로팅 채팅 패널

### 목적
어디서든 멤버 이름 클릭 → 페이지 이동 없이 플로팅 패널에서 바로 1:1 채팅

### 트리거 포인트

| 화면 | 위치 |
|------|------|
| 프로젝트 상세 | 팀원 목록 |
| 업무 상세 | 담당자, 생성자 |
| 팀 설정 | 멤버 목록 |
| 게시판 | 글/댓글 작성자 |
| 출퇴근 현황 | 팀원 이름 |

### 동작 흐름

1. 멤버 이름 클릭 → 팝오버: [1:1 채팅] [프로필 보기]
2. [1:1 채팅] → 우측 하단 플로팅 패널 열림
3. 기존 채팅방 있으면 재사용, 없으면 자동 생성

### 패널 기능

| 기능 | 설명 |
|------|------|
| 최소화 | 하단에 이름만 표시 |
| 다중 패널 | 최대 3개 동시 |
| 알림 연동 | 새 메시지 뱃지 표시 |
| 채팅 페이지 이동 | □ 클릭 시 #/chat으로 이동 |

### 패널 크기
- 너비: 320px / 높이: 420px / 우측 하단 고정

### API
- 기존 채팅 API 그대로 사용 (신규 API 불필요)
