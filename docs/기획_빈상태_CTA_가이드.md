# 빈 상태(Empty State) + CTA 가이드

> 작성일: 2026-03-18 | 우선순위: A | 대상: 프론트엔드 개발자

## 1. 설계 원칙

- **모든 리스트/테이블 페이지**는 데이터가 0건일 때 빈 상태 UI를 표시한다
- 빈 상태는 **아이콘 + 메시지 + CTA 버튼** 3요소로 구성한다
- CTA 버튼은 해당 페이지에서 가장 자연스러운 **첫 번째 행동**으로 연결한다
- 검색/필터 결과가 0건인 경우는 별도 문구를 사용한다

## 2. 공통 스타일 규격

```
컨테이너: py-16 flex flex-col items-center justify-center
아이콘: w-16 h-16 text-gray-300 dark:text-gray-600 mb-4
제목: text-lg font-medium text-gray-500 dark:text-gray-400 mb-2
설명: text-sm text-gray-400 dark:text-gray-500 mb-6
CTA 버튼: px-4 py-2 bg-indigo-600 text-white rounded-lg hover:bg-indigo-700 text-sm
```
