# Contract Sync v2 — 2차 개발 계획

> 1차 개발(Step 1~12) 완료 후 추가 구현이 필요한 기능 목록.
> 백엔드 API가 완성되어 있으나 프론트엔드 UI가 없는 항목 + 신규 기능으로 구분.

---

## 0. 2차 개발 목표

> **사용자 간 소통 비용 절감**

소통 비용은 크게 3가지 유형으로 발생한다:

| 유형 | 발생 상황 | 해결 방향 |
|------|-----------|-----------|
| **현황 파악** | "지금 뭐 하고 있어?" — 팀원 업무·프로젝트 상태를 매번 물어야 함 | 활동 로그, 대시보드, 워크로드 시각화 |
| **전달·확인** | "이거 봤어?" — 변경/코멘트를 상대방이 인지했는지 알 수 없음 | 실시간 알림, 읽음 표시, @멘션, 포털 피드백 |
| **정보 탐색** | "그거 어디 있어?" — 필요한 정보를 찾으려고 동료에게 물어봄 | 글로벌 검색, 데이터 내보내기, 활동 이력 |

모든 기능의 우선순위는 이 목표 기준으로 평가한다.

## 1. 프론트엔드 미구현 (백엔드 API 존재)

### 1-1. 활동 로그 페이지 ★ 최우선

| 항목 | 내용 |
|------|------|
| 소통 비용 | **현황 파악** — 누가 무엇을 했는지 시스템에서 바로 확인 |
| 백엔드 | `app/api/endpoints/activity.py` — `GET /activity` (프로젝트/팀 필터, 페이지네이션) |
| 프론트 현황 | UI 없음 |
| 구현 필요 | 활동 로그 페이지(`#/activity`), 필터(프로젝트/팀/날짜), 타임라인 UI |
| 파일 | `static/js/main.js`, `templates/index.html` |

### 1-2. 대시보드 고도화 ★ 최우선

| 항목 | 내용 |
|------|------|
| 소통 비용 | **현황 파악** — 프로젝트 전체 현황을 한눈에 파악, 보고 회의 축소 |
| 백엔드 | `app/api/endpoints/dashboard.py` — revenue, workload, ai-insights 3개 API 미호출 |
| 프론트 현황 | `dashboardPage()`가 기본 통계만 표시, 3개 API 미사용 |
| 구현 필요 | 매출 추이 차트(6개월), 팀 워크로드 시각화, AI 인사이트 카드 |
| 참고 | Chart.js 또는 CSS 기반 차트 |
| 파일 | `static/js/main.js`, `templates/index.html` |

### 1-3. 알림 센터 개선 ★ 최우선

| 항목 | 내용 |
|------|------|
| 소통 비용 | **전달·확인** — 변경 사항을 놓치지 않고 인지 |
| 백엔드 | `app/api/endpoints/notifications.py` — 목록/읽음처리/삭제 API 존재 |
| 프론트 현황 | 헤더 벨 아이콘 + 드롭다운 목록만 존재 |
| 구현 필요 | 알림 타입별 필터, 알림 삭제, 전체 읽음 처리, 알림 설정 |
| 파일 | `static/js/main.js`, `templates/index.html` |

### 1-4. 팀 생성 + 팀 설정 페이지 ★ 높음

| 항목 | 내용 |
|------|------|
| 소통 비용 | 간접 — 팀 구조 관리가 원활해야 알림·권한이 정확히 동작 |
| 백엔드 | `app/api/endpoints/teams.py` — 8개 엔드포인트 (CRUD + 멤버 초대/제거/역할변경) |
| 프론트 현황 | 사이드바 팀 전환 드롭다운만 존재 |
| 구현 필요 | 팀 생성 모달, 팀 설정 페이지(`#/team-settings`), 멤버 관리, 역할 변경, 팀 삭제 |
| 파일 | `static/js/main.js`, `templates/index.html` |

### 1-5. 설정 페이지 확장 ★ 보통

| 항목 | 내용 |
|------|------|
| 소통 비용 | 간접 — 알림 설정으로 불필요한 알림 제어 |
| 백엔드 | `PATCH /auth/profile` (이름 변경) 구현 완료 |
| 프론트 현황 | `settingsPage()`는 캘린더 연동만 표시 |
| 구현 필요 | 프로필 편집(이름), 비밀번호 변경, 알림 설정, 계정 삭제 |
| 파일 | `static/js/main.js`, `templates/index.html` |

## 2. 프론트엔드 개선

### 2-1. 댓글 @멘션 자동완성 ★ 최우선

| 항목 | 내용 |
|------|------|
| 소통 비용 | **전달·확인** — 특정 사람에게 정확히 전달, 메신저 이동 없이 시스템 내 소통 |
| 백엔드 | `comments.py` — @mention 추출 + 이메일 알림 구현 완료 |
| 프론트 현황 | 댓글 렌더링에 멘션 하이라이트는 있지만 입력 시 자동완성 없음 |
| 구현 필요 | 텍스트 입력에서 `@` 입력 시 팀 멤버 드롭다운 |

### 2-2. 포털 피드백 제출 UI ★ 최우선

| 항목 | 내용 |
|------|------|
| 소통 비용 | **전달·확인** — 발주처가 시스템 안에서 직접 피드백, 전화/메일 소통 감소 |
| 백엔드 | `POST /feedback/{token}` — 비로그인 피드백 제출 API 존재 |
| 프론트 현황 | 포털에서 조회만 가능, 피드백 제출 UI 미구현 |
| 구현 필요 | 포털 페이지에서 직접 피드백(승인/수정요청) 제출 |

### 2-3. 모바일 네비게이션 개선 ★ 높음

| 항목 | 내용 |
|------|------|
| 소통 비용 | **정보 탐색** — 모바일에서 페이지 접근 불가 → 데스크톱 사용자에게 대신 확인 요청 |
| 현황 | 하단 탭바에 4개만 표시 (대시보드/발주처/프로젝트/업무) |
| 문제 | 보고서, 수금, 템플릿, 설정 등 7개+ 페이지 접근 불가 |
| 구현 필요 | "더보기" 탭 추가 또는 스크롤 가능 탭바 |
| 파일 | `templates/index.html` (line 2732-2747) |

### 2-4. 캘린더 연동 UI 보강 ★ 보통

| 항목 | 내용 |
|------|------|
| 소통 비용 | 간접 — 일정 자동 동기화로 "이 일정 언제야?" 질문 감소 |
| 현황 | OAuth 연결/해제/동기화 버튼만 존재 |
| 구현 필요 | 동기화 상태 표시, 마지막 동기화 시간, 캘린더 선택 UI |

## 3. 신규 기능 (백엔드 + 프론트엔드 모두 필요)

### 3-1. 실시간 알림 (WebSocket/SSE) ★ 최우선 — 신규

| 항목 | 내용 |
|------|------|
| 소통 비용 | **전달·확인** — 페이지 새로고침 없이 즉시 변경 감지 → "봤어?" 질문 제거 |
| 설명 | 업무 상태 변경, 새 댓글, 멘션 등 이벤트를 실시간으로 브라우저에 전달 |
| 현황 | 없음 (폴링 기반) |
| 구현 | FastAPI WebSocket 또는 SSE 엔드포인트 + 프론트 이벤트 리스너 |
| 연관 | 알림 센터(1-3)와 함께 구현 시 시너지 극대화 |

### 3-2. 업무 상태 변경 시 자동 알림 ★ 최우선 — 신규

| 항목 | 내용 |
|------|------|
| 소통 비용 | **현황 파악** — 담당자가 상태 변경하면 관련자에게 즉시 알림 → 현황 질문 제거 |
| 설명 | 업무 상태 변경(진행중→완료 등) 시 프로젝트 관리자·팀원에게 자동 알림 생성 |
| 현황 | 없음 |
| 구현 | 업무 PATCH 시 알림 자동 생성 로직 + 실시간 전달(3-1 연계) |
| 연관 | 실시간 알림(3-1), 알림 센터(1-3) |

### 3-3. 댓글 답글 (스레드) ★ 최우선 — 신규

| 항목 | 내용 |
|------|------|
| 소통 비용 | **전달·확인** — 맥락 있는 대화를 시스템 안에서 유지 → 메신저/이메일 이동 감소 |
| 설명 | 댓글에 답글을 달 수 있는 스레드 구조 |
| 현황 | 댓글은 flat list로만 표시 |
| 구현 | `comments` 테이블에 `parent_id` 컬럼 추가, 백엔드 답글 API, 프론트 스레드 UI |

### 3-4. 읽음 표시 (댓글/알림) ★ 최우선 — 신규

| 항목 | 내용 |
|------|------|
| 소통 비용 | **전달·확인** — 상대방이 확인했는지 바로 보임 → "이거 봤어?" 질문 제거 |
| 설명 | 댓글·알림에 읽음/안읽음 표시, 댓글에는 읽은 사람 수 표시 |
| 현황 | 알림에 `is_read` 필드는 있으나 댓글에는 없음 |
| 구현 | `comment_reads` 테이블 신규, 읽음 처리 API, 프론트 읽음 표시 UI |

### 3-5. 주간 요약 리포트 자동 생성 ★ 높음 — 신규

| 항목 | 내용 |
|------|------|
| 소통 비용 | **현황 파악** — 매주 팀 진행현황 자동 정리 → 정기 보고 회의 축소/대체 |
| 설명 | 주간 단위로 완료 업무, 진행 중 업무, 지연 업무를 자동 집계하여 리포트 생성 |
| 현황 | 없음 |
| 구현 | 스케줄러 기반 자동 집계 + 이메일/알림 발송 + 리포트 조회 페이지 |
| 연관 | 대시보드(1-2), AI 인사이트 |

### 3-6. 글로벌 검색 / 커맨드 팔레트 ★ 높음

| 항목 | 내용 |
|------|------|
| 소통 비용 | **정보 탐색** — 프로젝트/업무/발주처를 직접 찾기 → 동료에게 묻지 않음 |
| 설명 | `Ctrl+K` / `Cmd+K`로 프로젝트/업무/발주처 통합 검색 |
| 현황 | 각 페이지별 개별 검색만 존재 |
| 구현 | 프론트엔드 모달 + 기존 검색 API 활용 |

### 3-7. 비밀번호 변경 ★ 보통

### 3-11. 구글 로그인 (Google OAuth) ★ 높음 — 신규

| 항목 | 내용 |
|------|------|
| 소통 비용 | **전달·확인** — 가입/로그인 허들 감소 → 팀원이 시스템을 직접 사용, 대리 확인 요청 제거 |
| 설명 | Google 계정으로 원클릭 회원가입/로그인, 기존 계정과 Google 계정 연동 |

| 연관 | 설정 페이지(1-5)에서 Google 계정 연동/해제 UI |
