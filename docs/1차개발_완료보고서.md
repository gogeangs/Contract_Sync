## 1. 프로젝트 개요

### 1.1 서비스 소개

Contract Sync는 **고객·업무 중심 프로젝트 관리 플랫폼**입니다.
발주처 등록부터 프로젝트 관리, 업무 수행, 완료 보고, 피드백, 수금까지 전체 비즈니스 프로세스를 하나의 서비스에서 처리합니다.

### 1.2 비전

> **"사용자가 AI를 찾아가는 서비스"에서 "AI가 사용자에게 다가오는 서비스"로**

실무자가 메뉴를 찾아다니지 않아도, AI가 맥락을 파악하고 다음 행동을 제안하며, 자연어 한 마디로 업무를 처리할 수 있는 구조.

### 1.3 기술 스택

| 구분 | 기술 |
|------|------|
| 백엔드 | FastAPI (Python 3.12), SQLite (aiosqlite), SQLAlchemy 비동기 |
| 프론트엔드 | HTML5 + Tailwind CSS + Alpine.js 3.x (SPA) |
| AI 엔진 | Google Gemini 2.0 Flash |
| 이메일 | Gmail API (Google Workspace) + Resend 폴백 |
| 외부 연동 | Google Sheets API, Google Calendar API, Figma API |
| 배포 | Railway (Hobby Plan) |
| 인증 | Google OAuth 2.0 (수동 httpx 구현) |
